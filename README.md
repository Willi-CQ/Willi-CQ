# Willi Horn

I'm 20 and the founder of [ConstructQ](https://constructq.de). I'm doing my M.Sc. in Industrial Engineering and Management at TU Berlin, specializing in AI Engineering.

ConstructQ is an AI agent for construction projects. It reads a project's plans, mail, photos and cost files and answers with the source document. It can create defects and control costs, but only after a human approves. Every action goes into an audit trail that follows German GoBD rules. I build it myself.

## No public repos

The code is in private repositories. ConstructQ is a commercial product and works with customers' project data. The backend runs on Azure in the EU. What I can show publicly is on [constructq.de](https://constructq.de).

## Stack

Python (FastAPI), TypeScript and React, Rust (Tauri), PostgreSQL, Azure.
